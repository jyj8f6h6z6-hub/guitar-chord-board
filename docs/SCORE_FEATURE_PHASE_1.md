# 拍照視譜與智慧歌譜：第一期（0.4.0）

## 已完成

### 模式二

- 上傳 PNG、JPG、JPEG、PDF。
- PDF 在瀏覽器中轉成逐頁圖片。
- OCR 辨識譜面上已經印出的和弦文字。
- 顯示可編輯的辨識結果。
- 可取代歌曲和弦清單，或附加在現有清單後方。

### 模式四：智慧歌譜

- 上傳圖片或多頁 PDF。
- 辨識圖片上的既有和弦及位置。
- 選擇原調與新調，批次移調。
- 在原位置使用新和弦覆蓋舊文字。
- 可逐筆修改或刪除辨識結果。
- 可點擊歌譜手動新增和弦。
- 可下載單頁 PNG。
- 可下載全部頁面的 PDF。
- 可將結果送回模式二。

## 尚未完成

只有旋律、沒有和弦名稱的五線譜、六線譜與簡譜，需要真正的 Optical Music Recognition（OMR）：

1. 偵測譜表、小節線、拍號及調號。
2. 辨識音符高度、時值、連音與休止符。
3. 重建每小節的音樂事件。
4. 根據使用者選擇的調性推演和聲。
5. 提供每小節候選和弦與信心值。
6. 讓使用者確認後寫回歌譜。

這部分不應以一般文字 OCR 假裝完成，後續需要 Python／Java OMR 模型服務，再由目前 React 網站呼叫 API。

## 新增 dependencies

```bash
npm install tesseract.js@7 pdfjs-dist@6.2.108 jspdf@4.2.1
```

- `tesseract.js`：瀏覽器文字 OCR。
- `pdfjs-dist`：PDF 逐頁渲染。
- `jspdf`：下載標記完成的多頁 PDF。
